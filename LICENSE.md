# Licensing

Korean Samjho is split into two differently-licensed parts.

## Application source code — Apache License 2.0

Everything under `app/`, `content/tools/`, and the Gradle build files.

Full text: <https://www.apache.org/licenses/LICENSE-2.0>

## Educational content — CC BY-SA 4.0

Everything under `content/src/` and the generated `content.db`.

Full text: <https://creativecommons.org/licenses/by-sa/4.0/>

Share-alike is not optional here: Korean lexical data is verified against
**한국어기초사전 (Basic Korean Dictionary)**, published by the **National Institute
of Korean Language** under **CC BY-SA 2.0 KR**, so derived content inherits the
share-alike obligation. NIKL is attributed in-app under Settings → About →
Content sources.

Every example sentence, grammar explanation, practice question, and all Urdu and
Hindi text is original work written for this app. krdict's own example sentences
are largely drawn from copyrighted publications and are **not** redistributable,
so none are reused. See [`docs/01-research.md`](docs/01-research.md) §1.3.
